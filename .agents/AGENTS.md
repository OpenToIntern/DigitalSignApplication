# Project Rules

- **Do not ever commit or push any code unless the user explicitly tells you to.** Keep all changes unstaged/staged locally until requested.
- **Only run the project on localhost.**
- **Do not run any tests.** The user will verify and test everything themselves.
- **If the user asks you to add code to GitHub, create a Pull Request only.** Never push directly to the `develop` or `main` branch.
- **Code must never be merged into `develop` or `main` unless it has been reviewed and approved by someone else.** Keep all changes in the PR until reviewed.
